# Space-App-Challengue-Harmonization-Of-MODIS-and-VIIRS-Hotspot

## Use of AI

We used Claude (Anthropic), an AI assistant, during the development of this project:

- **Code:** writing and refactoring JavaScript modules for geodesy, harmonization, analysis, charts, map, interface and CSV export, following the structure and naming rules defined by the team.
- **Tests:** writing automated tests with the Node.js test runner.
- **Data pipeline:** writing the scripts that download NASA FIRMS active fire data and build the map tiles.
- **Understanding:** explaining the FIRMS documentation, the MODIS and VIIRS user guides and the harmonization method.

The team defined the problem, the features and the scope, reviewed and tested every change, and made all design decisions. No AI-generated images, videos or audio are used. The synthetic demo data is produced by our own code and is always labeled as DEMO DATA in the interface and in exported files.
